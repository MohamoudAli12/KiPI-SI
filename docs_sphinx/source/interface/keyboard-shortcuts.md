# Keyboard shortcuts

## Every key

The view keys work once you have clicked in the 3D view, so that Home and letters still reach the lists and text boxes. The rest work anywhere in the main window. Each button's tooltip names its key. On macOS, **Ctrl** is the **Command** key.

```{list-table}
:header-rows: 1
:class: kipi-table

* - Key
  - What it does
* - **Home**
  - Iso view (in the 3D view)
* - **Z** / **Shift+Z**
  - Top / bottom view (in the 3D view)
* - **Ctrl+O**
  - **Open…** (standalone) or **Open snapshot…** (plugin)
* - **F5**
  - **Reload**, or **Load from KiCad**
* - **Ctrl+S**
  - **Save snapshot…**
* - **F12**
  - **Screenshot…**
* - **F11**
  - Full screen and back for the Board, setup or Log panel you last clicked in, which floats it first
* - **Ctrl+Shift+O**
  - **Open results…**
* - **Ctrl+L**
  - The {ref}`Stackup window <stackup>`
* - **Ctrl+T**
  - The **Power tree**
* - **Ctrl+1** / **Ctrl+2** / **Ctrl+3** / **Ctrl+4**
  - DC / AC / Coupled Noise / Signal Integrity mode
* - **Ctrl+Enter**
  - Solve: **Solve all** in DC mode, **Solve rail** in AC mode, when the button can be pressed
* - **Esc**
  - **Cancel** the running operation
* - **F1**
  - This guide
```
