# 3D view and mouse

## Navigating and probing

```{list-table}
:header-rows: 1
:class: kipi-table

* - Action
  - Mouse
* - Rotate
  - Left-drag
* - Pan
  - Shift + left-drag, or middle-drag
* - Zoom
  - Scroll wheel
* - Probe / identify
  - Left-click copper or a via. The result goes to the {ref}`Info <info>` box and the status bar. Clicks pass through {ref}`part models <part-models>`.
```

In the panels the scroll wheel always scrolls the panel. It never changes the number, list or slider under the pointer: type a value, use the arrow keys or the spin buttons, or click the list instead.

In AC mode two more tabs appear beside **3D view**: **Impedance**, with the {ref}`impedance plot <ac-plot>`, and **Board map**, with the {ref}`mesh and parts of the solve <ac-map>`.
